## 1. Цель работы с постановкой задачи

### 1.1. Цель работы

Изучить теорию конечных автоматов, освоить построение детерминированных (ДКА) и недетерминированных (НКА) конечных автоматов в системе JFLAP, а также реализовать их программно на языке Python с табличным представлением автомата.

### 1.2. Постановка задачи а) — ДКА

Построить ДКА, допускающий в алфавите `{0, 1}` все цепочки, в которых символ `1` следует непосредственно за парой `00`.

Примеры принадлежащих цепочек: `100`, `0010`, `0010011001`.  
Примеры не принадлежащих цепочек: `0001`, `0100`.

### 1.3. Постановка задачи б) — НКА

Построить НКА, допускающий цепочки в алфавите `Z = {0, 1}`, в которых содержится два нуля, разделённых позициями в количестве, кратном 4.

Примечание: нуль тоже кратен 4.

## 2. Графы переходов полученных ДКА и НКА

### 2.1. Граф переходов ДКА (задача а)

**Условие:** запрещена подстрока `000`.

**Состояния:**

| Состояние | Смысл | Initial | Final |
|-----------|-------|---------|-------|
| q0 | нет нулей в конце (или пусто) | да | да |
| q1 | один `0` в конце | нет | да |
| q2 | два `0` в конце | нет | да |
| q3 | ловушка (встретили `000`) | нет | нет |

**Таблица переходов:**

| Из | 0 | 1 |
|----|---|---|
| →q0 | q1 | q0 |
| q1 | q2 | q0 |
| q2 | q3 | q0 |
| q3 | q3 | q3 |

**Граф переходов:**

```
        0        0        0
(q0) ────→ (q1) ────→ (q2) ────→ (q3) ⟲ 0,1
 ↑  │       │          │
 │  │ 1     │ 1        │ 1
 └──┘       └──────────┘
```

- q0 — начальное и допускающее (двойной круг + треугольник).
- q1, q2 — допускающие (двойной круг).
- q3 — не допускающее (одинарный круг), петля `0, 1`.

### 2.2. Граф переходов НКА (задача б)

**Условие:** существуют два нуля, между которыми количество символов кратно 4.

**Состояния:**

| Состояние | Смысл | Initial | Final |
|-----------|-------|---------|-------|
| q0 | ищем первый ноль | да | нет |
| q1 | нашли первый ноль, отсчитываем 4 символа | нет | нет |
| q2 | отсчитали 1 символ | нет | нет |
| q3 | отсчитали 2 символа | нет | нет |
| q4 | отсчитали 3 символа | нет | нет |
| q5 | нашли второй ноль на нужном расстоянии | нет | да |

**Таблица переходов:**

| Из | 0 | 1 |
|----|---|---|
| →q0 | q0, q1 | q0 |
| q1 | q5, q2 | q2 |
| q2 | q3 | q3 |
| q3 | q4 | q4 |
| q4 | q1 | q1 |
| q5 | q5 | q5 |

Недетерминизм: из q0 по `0` — два перехода; из q1 по `0` — два перехода.

**Граф переходов:**

```
                 0
         ┌──────────────┐
         │              ▼
        (q0) ──0──→ (q1) ──0──→ (q5) ⟲ 0,1
         │  ▲        │  ▲
         │  │        │  │
         │  1        │  │ 1
         │  │        ▼  │
         │  └────── (q2)
         │            │
         │           0,1
         │            ▼
         │          (q3)
         │            │
         │           0,1
         │            ▼
         └────────── (q4)
```

## 3. Перехваты экранов при пошаговом выполнении процесса распознавания

### 3.1. ДКА — пошаговое распознавание

*(здесь вставляются скриншоты из JFLAP: окно `Step by State` для цепочек `100`, `0010`, `0010011001`, `0001`, `0100`)*

**Пример для цепочки `100`:**

```
q0 --1--> q0 --0--> q1 --0--> q2  → ACCEPTED
```

**Пример для цепочки `0001`:**

```
q0 --0--> q1 --0--> q2 --0--> q3 --1--> q3  → REJECTED
```

### 3.2. НКА — пошаговое распознавание

*(здесь вставляются скриншоты из JFLAP: окно `Step with Closure` для цепочек `00`, `011110`, `011111110`, `010`)*

**Пример для цепочки `00`:**

```
q0 --0--> {q0, q1} --0--> {q0, q5}  → ACCEPTED
```

**Пример для цепочки `011110`:**

```
q0 --0--> {q0, q1} --1--> {q0, q2} --1--> {q0, q3} --1--> {q0, q4} --1--> {q0, q1} --0--> {q0, q5}  → ACCEPTED
```

**Пример для цепочки `010`:**

```
q0 --0--> {q0, q1} --1--> {q0, q2} --0--> {q0, q3}  → REJECTED
```

## 4. Программная реализация

### 4.1. ДКА (Python)

```python
# ============================================================
# ДКА: запрещена подстрока "000"
# Табличное представление автомата + консольный ввод
# ============================================================

TRANSITIONS = [
    {0: 1, 1: 0},   # q0
    {0: 2, 1: 0},   # q1
    {0: 3, 1: 0},   # q2
    {0: 3, 1: 3},   # q3 (ловушка)
]

INITIAL_STATE = 0
FINAL_STATES = {0, 1, 2}
STATE_NAMES = ["q0", "q1", "q2", "q3"]


def recognize(chain):
    state = INITIAL_STATE
    path = [STATE_NAMES[state]]

    for ch in chain:
        if ch == '0':
            symbol = 0
        elif ch == '1':
            symbol = 1
        else:
            return False, path, f"недопустимый символ '{ch}'"

        state = TRANSITIONS[state][symbol]
        path.append(STATE_NAMES[state])

    accepted = state in FINAL_STATES
    return accepted, path, None


def main():
    print("=" * 60)
    print("ДКА: запрещена подстрока '000'")
    print("Алфавит: {0, 1}")
    print("Введите цепочку или 'exit' для выхода.")
    print("=" * 60)

    while True:
        try:
            chain = input("\n> ").strip()
        except EOFError:
            break

        if chain == "exit":
            print("Выход.")
            break

        accepted, path, error = recognize(chain)
        display = chain if chain != "" else "(пустая)"
        print(f"\nЦепочка: {display}")
        if error is not None:
            print(f"  Ошибка: {error}")
            print("  Результат: REJECTED")
        else:
            print(f"  Путь: {' -> '.join(path)}")
            print(f"  Результат: {'ACCEPTED' if accepted else 'REJECTED'}")


if __name__ == "__main__":
    main()
```

### 4.2. НКА (Python)

```python
# ============================================================
# НКА: два нуля, между которыми число символов кратно 4
# Табличное представление автомата + консольный ввод
# ============================================================

TRANSITIONS = {
    (0, 0): [0, 1], (0, 1): [0],
    (1, 0): [5, 2], (1, 1): [2],
    (2, 0): [3], (2, 1): [3],
    (3, 0): [4], (3, 1): [4],
    (4, 0): [1], (4, 1): [1],
    (5, 0): [5], (5, 1): [5],
}

INITIAL_STATE = 0
FINAL_STATES = {5}
STATE_NAMES = ["q0", "q1", "q2", "q3", "q4", "q5"]


def recognize(chain):
    current = {INITIAL_STATE}
    path = [STATE_NAMES[INITIAL_STATE]]

    for ch in chain:
        if ch == '0':
            symbol = 0
        elif ch == '1':
            symbol = 1
        else:
            return False, path, f"недопустимый символ '{ch}'"

        next_states = set()
        for state in current:
            if (state, symbol) in TRANSITIONS:
                for ns in TRANSITIONS[(state, symbol)]:
                    next_states.add(ns)

        if not next_states:
            return False, path, None

        current = next_states
        path.append("{" + ",".join(STATE_NAMES[s] for s in sorted(current)) + "}")

    accepted = len(current & FINAL_STATES) > 0
    return accepted, path, None


def main():
    print("=" * 60)
    print("НКА: два нуля, между которыми число символов кратно 4")
    print("Алфавит: {0, 1}")
    print("Введите цепочку или 'exit' для выхода.")
    print("=" * 60)

    while True:
        try:
            chain = input("\n> ").strip()
        except EOFError:
            break

        if chain == "exit":
            print("Выход.")
            break

        accepted, path, error = recognize(chain)
        display = chain if chain != "" else "(пустая)"
        print(f"\nЦепочка: {display}")
        if error is not None:
            print(f"  Ошибка: {error}")
            print("  Результат: REJECTED")
        else:
            print(f"  Путь: {' -> '.join(path)}")
            print(f"  Результат: {'ACCEPTED' if accepted else 'REJECTED'}")


if __name__ == "__main__":
    main()
```
